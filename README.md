# Πρόοδος — PWA για κινητό (offline)

## Εγκατάσταση (μία φορά, ~5 λεπτά, 0€)

1. Φτιάξε νέο **public** repo στο GitHub (π.χ. `progress`).
2. Ανέβασε όλα τα αρχεία (index.html, sw.js, manifest.json, φάκελο icons/).
3. Settings → Pages → Source: `Deploy from a branch` → `main` / `root` → Save.
4. Σε 1–2 λεπτά θα είναι στο `https://<username>.github.io/progress/`.
5. Άνοιξέ το **από το κινητό**:
   - **iPhone**: Safari → Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».
   - **Android**: Chrome → ⋮ → «Εγκατάσταση εφαρμογής».
6. Από εδώ και πέρα ανοίγει από το εικονίδιο και δουλεύει χωρίς internet.

## Σημαντικό
- Τα δεδομένα μένουν **μόνο στο κινητό**. Κάνε **Export** από τις Ρυθμίσεις κάθε εβδομάδα.
- Στο iPhone άνοιγέ το πάντα από το εικονίδιο της αρχικής οθόνης, όχι από το Safari.
- Αν αλλάξεις κώδικα: ανέβασε τον αριθμό `CACHE` στο `sw.js` (progress-v2 κ.λπ.),
  κάνε push, και άνοιξε την εφαρμογή 2 φορές με internet για να πάρει την ενημέρωση.

## Τοπική δοκιμή στον υπολογιστή
```
python3 -m http.server 8000
```
και άνοιξε `http://localhost:8000` (DevTools → Device toolbar για προβολή κινητού).
